# Scrollify
A social media simulator about addiction
## Build Guide
1. Make sure you have Xcode 26. This playground does not work on Swift Playgrounds.
2. Clone the repo.
3. Open the playground in Xcode 26.
4. Click on the play button at the top of the sidebar. Make sure the build destination is set to an iPad, My Mac (Designed for iPad) or an iPad Simulator.
